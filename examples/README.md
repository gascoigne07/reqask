# Чужой документ для проверки агента

Здесь агент проверен на документе другого автора, из другой области и на другом языке. Так видно, что промпты и правила не подогнаны под выданный документ, а заодно проверено чтение настоящего PDF: таблицы, колонтитулы, оглавление. Под этот документ агент не настраивался.

Документ: спецификация требований к доработкам Moodle для университета Пьюджет-Саунд (2007, английский, 14 страниц).

## Где взять файл

Самого PDF в репозитории нет: на его страницах стоит пометка авторов «Confidential», поэтому даём ссылку на первоисточник.

1. Скачайте архив `requirements.zip` из набора PURE на Zenodo: https://doi.org/10.5281/zenodo.1414117
2. Возьмите из архива файл `req/2007 - puget sound.pdf`.
3. Положите его сюда под именем `examples/pure-puget-sound.pdf`.
4. Сверьте контрольную сумму (`shasum -a 256 examples/pure-puget-sound.pdf`):
   `bc8fea411b7e40f114e453f09451cd3777da5f218f0d1414fbb640ec5ed9dce8`

Источник: Alessio Ferrari, Giorgio Oronzo Spagnolo, Stefania Gnesi. PURE: a Dataset of Public Requirements Documents. Zenodo, 2018. Набор опубликован под лицензией CC BY 4.0.

## Запуск

```bash
uv run main.py --input examples/pure-puget-sound.pdf --output examples/pure-puget-sound.report.md
```
