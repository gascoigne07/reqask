# Проверка агента на других документах

Здесь агент проверен на двух документах помимо выданного. Первый мы написали сами и подсадили в него известные дефекты, чтобы посчитать, сколько агент найдёт. Второй взят из открытого набора PURE: у него другой автор, другая область и английский язык, а дефекты в нём вслепую выписал человек.

Все отчёты в этой папке сформировал агент, руками они не правились. Агент записал их под рабочими именами, а сюда они положены с новыми, поэтому в журнале шагов (шаг 9) стоят старые имена файлов.

## Складской документ с подсаженными дефектами

Из трёх чистых требований без своих замечаний осталось одно, C-03 (строка 117, только HTTPS). Оно стоит только в списке из 13 требований общего замечания S-26 о том, что критерии приёмки покрывают малую часть требований. На C-01 (строка 46, запрет удаления позиции с остатком) агент поставил два замечания уровня MAJOR: D-05 про отрицательный остаток и S-15 про позицию с нулевым остатком, но с резервом или товаром в пути. На C-02 (строка 80, кладовщик не видит раздел «Отчёты») он поставил D-19 уровня MAJOR: запрещён пункт меню, а прямой доступ к разделу не запрещён. Эталон допускал к чистым требованиям только одно замечание, уровня MINOR, про текст сообщения к C-01. По эталону эти три замечания лишние.

Условия проверки стоит держать в голове. Документ и эталон составили мы сами, а не посторонний человек. Складских примеров в промптах агента нет, это можно проверить:

```bash
grep -inE "склад|товар|кладовщ" src/reqask/prompts.py
```

Команда ничего не находит.

## Спецификация Moodle из набора PURE

Спецификация требований к доработкам Moodle для университета Пьюджет-Саунд (2007, английский, 14 страниц). Под этот документ агент не настраивался. Заодно на нём проверено чтение настоящего PDF: таблицы, колонтитулы, оглавление.

### Где взять файл

Самого PDF в репозитории нет: на его страницах стоит пометка авторов «Confidential», поэтому даём ссылку на первоисточник.

1. Скачайте архив `requirements.zip` из набора PURE на Zenodo: https://doi.org/10.5281/zenodo.1414117
2. Возьмите из архива файл `req/2007 - puget sound.pdf`.
3. Положите его сюда под именем `examples/pure-puget-sound.pdf`.
4. Сверьте контрольную сумму (`shasum -a 256 examples/pure-puget-sound.pdf`):
   `bc8fea411b7e40f114e453f09451cd3777da5f218f0d1414fbb640ec5ed9dce8`

Источник: Alessio Ferrari, Giorgio Oronzo Spagnolo, Stefania Gnesi. PURE: a Dataset of Public Requirements Documents. Zenodo, 2018. Набор опубликован под лицензией CC BY 4.0.

## Как повторить

Отчёты пишутся в папку `out/`, чтобы не затереть отчёты в этой папке. Состав замечаний меняется от прогона к прогону, числа выше получены на одном прогоне каждого документа.

```bash
uv run main.py --input examples/foreign-doc.md --output out/foreign-doc.report.md
```

```bash
uv run main.py --input examples/pure-puget-sound.pdf --output out/pure-puget-sound.report.md
```
